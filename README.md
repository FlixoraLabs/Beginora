# Beginora (Android)

Build the APK without installing anything:
1. Create a free GitHub account and a new repository.
2. Upload everything in this folder (including the hidden .github folder).
3. Open the Actions tab, wait about 5-10 minutes for "Build Android APK" to finish.
4. Open the finished run, download the Beginora-APK artifact, unzip it and install app-debug.apk on your phone.
5. On first launch, allow notifications.
